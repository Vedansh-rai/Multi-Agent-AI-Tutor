# Problem-Solving Templates

## Template 1: Solve a Quadratic Equation
1. Write equation in standard form: ax² + bx + c = 0
2. Calculate discriminant: D = b² - 4ac
3. Determine nature of roots from D
4. Apply quadratic formula: x = (-b ± √D) / (2a)
5. Simplify and verify by substituting back

## Template 2: Find Derivative
1. Identify the function type (polynomial, trig, exponential, composite)
2. Choose appropriate rule (power, chain, product, quotient)
3. Apply the rule step by step
4. Simplify the result
5. Verify by checking a known point if possible

## Template 3: Evaluate a Definite Integral
1. Identify integrand type
2. Choose technique: direct formula, substitution, by parts, partial fractions
3. Find antiderivative F(x)
4. Apply Fundamental Theorem: F(b) - F(a)
5. Simplify the numerical result

## Template 4: Solve a Probability Problem
1. Define the sample space
2. Identify the event of interest
3. Determine if events are independent or conditional
4. Choose formula: direct counting, Bayes, complement, inclusion-exclusion
5. Calculate and verify P is between 0 and 1

## Template 5: Solve a Matrix Problem
1. Write the matrix explicitly
2. Identify what is asked (determinant, inverse, rank, eigenvalues)
3. Apply appropriate algorithm
4. Verify: A × A⁻¹ = I, or substitute eigenvalue back
5. State the final answer clearly

## Template 6: Optimization Problem
1. Define the objective function f(x)
2. Find f'(x) and set f'(x) = 0 for critical points
3. Use second derivative test: f''(x) > 0 → minimum, f''(x) < 0 → maximum
4. Check boundary values if domain is closed
5. Compare all candidates to find global max/min

## Template 7: System of Equations
1. Count equations and unknowns
2. Choose method: substitution, elimination, matrix (Cramer's/Row reduction)
3. Solve systematically
4. Verify solution in ALL original equations
5. State whether solution is unique, infinite, or none
